# Collision Registry

Every override of a vanilla path, and every collision (real or checked-and-cleared) between two
bundled modules, must be logged here — see section 11 of [`ARCHITECTURE.md`](ARCHITECTURE.md).
Nothing gets resolved silently.

## Como usar

- Toda nova integração (Fase 1 do fluxo de integração, seção 17) deve rodar
  `tools/audit_collisions.py` e revisar manualmente os itens que a ferramenta não consegue detectar
  automaticamente (Item/Recipe/Trait/Perk IDs, globals Lua, network module names — a ferramenta
  atual só compara caminhos relativos e Mod IDs; ver limitação documentada em
  `tools/audit_collisions.py`).
- Uma linha "Testado: pendente" significa que a colisão foi identificada mas ainda não passou por
  teste funcional dedicado em client + dedicated server — não é a mesma coisa que "sem risco".
- Nenhuma colisão deve ser removida desta tabela; se deixar de existir (módulo removido, arquivo não
  é mais override), marcar `Resolução` como `obsoleto — módulo removido em <data>` em vez de apagar
  a linha.
