## Colunas

- **Key**: `module_key` interno, usado em `docs/modules/<key>.md` e (para third-party) em
  `vendor/<key>/`.
- **Mod ID bundled**: Mod ID do PZ que carrega o módulo. Módulos próprios vivem dentro do submod
  `LasciviousScripts`; módulos de terceiros recebem seu próprio `LS_<Nome>` (ver seção 5.2 da
  arquitetura).
- **Upstream**: `próprio` para código autoral, ou `Workshop <id>` para conteúdo importado.
- **Versão**: versão reportada pelo próprio módulo (`Core.VERSION` para código autoral, versão do
  manifesto para third-party).
- **PTBR**: `sim` / `parcial` / `não aplicável` (quando o módulo não expõe texto ao jogador).
- **Status**: `ativo`, `desativado`, `pendente`, `removido`.
- **Risco**: avaliação qualitativa curta — motivo de risco entre parênteses quando não for óbvio.

## Como atualizar

Toda integração ou atualização de módulo (ver seção 17 e 18 da arquitetura) deve atualizar a linha
correspondente nesta tabela como parte da mesma alteração. Novas linhas entram em ordem alfabética
por `Key`.
